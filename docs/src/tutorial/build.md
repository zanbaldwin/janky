# 4. Build and import

In this step, you build the Anki package and import it into Anki. You use the three everyday
commands: `janky check`, `janky plan` and `janky build`.

## Check the project

Run `janky check`:

```console
$ janky check
9 notes are valid
```

`check` reads every file of the project and reports all the errors that it finds. It writes no
files. Run it each time you change a file.

## Look at the cards

This step is optional. Run `janky preview`:

```console
$ janky preview
Preview at http://127.0.0.1:5259/ — reload the page to read the files again, press Ctrl+C to stop
```

Open the address in your browser. The table on the left has one row for each card. Click a row to
see the card, and use **Front** and **Back** to turn it. The `gato` entry has no `production` key,
so its Production card has the label `empty`: Anki does not make that card.

Change `style.css`, save it, and reload the page to see the new colours. Press Ctrl+C in the
terminal when you are done. [preview](../cli/commands.md#preview) explains the page in full.

## Plan the build

Run `janky plan`:

```console
$ janky plan
Notes: 9 added, 0 changed, 0 removed, 0 moved, 0 unchanged
+ deck Spanish
+ deck Spanish::1 Vocabulary
+ deck Spanish::2 Phrases
+ preset Spanish
+ preset Spanish beginner
+ note type Spanish Word
+ note type Spanish Phrase
+ note hola in Spanish::2 Phrases
+ note que-tal in Spanish::2 Phrases
+ note donde-esta-el-bano in Spanish::2 Phrases
+ note casa in Spanish::1 Vocabulary
+ note perro in Spanish::1 Vocabulary
+ note gato in Spanish::1 Vocabulary
+ note pan in Spanish::1 Vocabulary
+ note manzana in Spanish::1 Vocabulary
+ note aguacate in Spanish::1 Vocabulary
+ media casa.png
When you import:
  Tick "Import any deck presets". Anki adds a preset only the first time.
```

`plan` shows what the next build changes, compared with the last build. This is the first build,
so everything is new (`+`). The `When you import:` lines tell you which import options to set in
Anki. `plan` also writes no files.

## Build the package

Run `janky build`:

```console
$ janky build
Notes: 9 added, 0 changed, 0 removed, 0 moved, 0 unchanged
+ deck Spanish
...
+ media casa.png
When you import:
  Tick "Import any deck presets". Anki adds a preset only the first time.

wrote .janky/build/spanish.apkg: 9 notes, 1 media file
In Anki, turn FSRS on. A package cannot change collection settings.
```

`build` prints the same plan, then writes two files:

- `.janky/build/spanish.apkg`, the package to import (the `output` of `deck.toml`)
- `deck.lock`, a new file in the project directory

Run `janky plan` again:

```console
$ janky plan
Notes: 0 added, 0 changed, 0 removed, 0 moved, 9 unchanged
No changes.
```

The files and the last build are the same now.

## Keep deck.lock

`deck.lock` holds the ids that link each entry to its note in Anki. Its first lines look like this
(your ids are different):

```toml
# Written by janky. Do not edit this file.
version = 1
namespace = "0be6f6b4b8011936c51c28b016cd18a5"

[deck]
id = 696704372687791
name = "Spanish"
...
```

> [!WARNING]
> Never edit or delete `deck.lock`. Without it, the next import adds a second copy of every note,
> with no review history. Keep it with your project, and commit it if you use Git.

[Changing content safely](../content/changing.md) explains how the lock protects your review
history.

## Import the package into Anki

1. Open Anki.
2. Select **File → Import**.
3. Select the file `.janky/build/spanish.apkg` in your project directory.

   > [!TIP]
   > Directories whose name starts with `.` are hidden on Linux. If the file window does not show
   > `.janky`, type the path, or turn on hidden files in the file window.

4. In the import options, tick **Import any deck presets**. `plan` told you to do this, because the
   package has new presets.
5. Make sure that **Update notes** and **Update note types** are set to **If newer** (the Anki
   default).
6. Select **Import**.
7. Turn on FSRS in Anki. FSRS is a setting of the whole collection, so a package cannot turn it on.
   `build` reminds you each time.

Anki now has the deck "Spanish" with the child decks "1 Vocabulary" and "2 Phrases", and the presets
"Spanish" and "Spanish beginner".

Study a few cards to see the result:

- The "casa" card shows "la casa", with "la" in colour, and the image.
- On the back, the examples are blurred. Tap them to show them.
- "casa" and "pan" also have a Production card (English to Spanish), because they have
  `production: true`. The other words have only a Recognition card.

You only tick **Import any deck presets** when `plan` asks for it. Anki adds a preset only once. If
you change a preset in `deck.toml` later, change it in Anki too.

[Importing into Anki](../cli/importing.md) explains every import option.
[The everyday workflow](../cli/workflow.md) explains check, plan and build.
